QuickHorse is a simple QoL mod that adds a keybind (default: H) that will automatically use the horse whistle, if it's in your inventory.

There is also an option to bypass the song the plays before summoning the horse.

# Additional Configuration
With [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) the following config options are available:
- Keybind (default: H) - Allows you to change the default keybind used to summon your horse
- Skip Delay (default: false) - Allows you to skip the delay caused by using the horse flute, thus making the summoning feel more instantaneous
- Require Flute in Inventory (default: true) - When set to false, allows you to summon your horse even if you don't have a flute in your inventory
